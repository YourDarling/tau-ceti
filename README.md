# Тау Кита — трилогия

Квест по командной строке Linux для 12–15 лет: три главы («Меланхолия», «Гнев», «Ревность»), по 7 забегов в каждой.
Терминал максимально похож на настоящий Parrot OS. Всё в одном файле `index.html`, работает без интернета и без установки.

Открыть онлайн: https://yourdarling.github.io/tau-ceti/

Глава I открыта сразу. Главы II и III открываются личным кодом, который ученик получает в финале предыдущей главы.
Прогресс хранится в браузере.
